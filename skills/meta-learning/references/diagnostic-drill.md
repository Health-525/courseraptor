# 习题课：诊断与补差

> 来源：Vygotsky 最近发展区理论；Guadagnoli & Lee Challenge Point Framework。
> 与 `practice-design` 的分工：那份管**编排一条能力进阶路径**（L1→L5），
> 这份管**一次习题课的循环**——从诊断暴露断点，到复检确认补上了。

## 核心循环（一次只跑一轮，跑完再判断要不要再来一轮）

1. **独立诊断**：给 3–5 道覆盖本节概念的题，不给提示、不讲评。目的是找出断点，不是打分。记录错在哪一步：读题 / 方法选择 / 计算执行 / 表述。
2. **定向复习**：只补诊断暴露的那 1–2 个断点，回讲定义、条件与反例，**不重讲整节**。讲完立刻回到题上。
3. **支架练习**：同结构、同表面特征的题，难度降一档，允许提示与分步引导。目标是让学习者自己走通因果链，不是做对。
4. **新鲜独立复检**：换一道**表面特征不同**的同类题，无提示，独立做。支架下会做不等于会做——这才是真检验。
5. **证据化下一步**：据复检结果分流：
   - 过了 → 进下一节或进变式题；
   - 还错 → 回到第 2 步，并把断点描述得更具体（不是「粗心」，是「没检查定义域」）；
   - 连续两轮卡在同一处 → 标记为需要外部帮助，建议找老师/同学，**不要继续加题**。

## 关键纪律

- **诊断题与复检题必须不同**：同一道题测两次测的是记忆，不是能力。
- **区分「不会」与「不熟」**：不会 = 概念缺失，回定义与反例；不熟 = 执行错误，加变式练习。归因错了会练错方向。
- **一次只补一个断点**：同时补三个等于没补。
- **难度锚在最近发展区**：目标成功率 60–80%。连续 3 题 >90% 升难度，<50% 降难度或加支架。
- **归因复用 `practice-design` 的七类**（知识盲区 / 理解偏差 / 提取失败 / 应用失误 / 计算粗心 / 时间不足 / 考试焦虑），别自造分类。
- **别把诊断做成测验**：诊断的价值在暴露断点。逐题讲评会把诊断拖成长课，正确做法是先做完题、再统一讲断点。
- **单题请求不开课**：用户只要「给我一道题」或「讲讲这题为什么错」，直接给题/讲解，不要启动整套五步循环。
