# 同学使用指南

[返回首页](../README.md) · [配置参考](configuration.md) · [完整能力](capabilities.md)

## 先体验，再配置

**推荐：下载 Windows 桌面安装包**——到 [Releases](https://github.com/Health-525/courseraptor/releases/latest) 选择 `desktop-win-x64-setup.exe` 结尾的文件，已内置 Node；也可选择便携版。正式 AI 对话需要自己的模型 API Key。有 Node.js 24 或更高版本的用户，也可下载源码后在项目目录运行离线演示：

```bash
npm ci
npm run demo
```

打开终端提示的地址（默认 `http://127.0.0.1:3211`）。这是固定剧本的离线演示，全部使用虚构数据，没有连接 AI。演示会话只保留在内存，服务重启即清空。不要在演示中填写个人资料。

结束演示按 `Ctrl+C`。正式使用运行 `npm start`，Windows 也可双击 `start.bat`。

## 第一次正式使用

1. 准备任一家内置厂商的 API Key（默认 DeepSeek，共 12 家可选，见[配置参考](configuration.md)），API 调用费用由你自己的模型服务账户承担。
2. 在「功能大厅 → 设置 → AI 模型」保存自己的 API Key 并检测连接；Key 加密保存在本机，通常无需编辑 `.env`。终端用户也可通过无参数 `/key` 进入安全录入流程。
3. 打开启动界面显示的网页地址，默认 `http://localhost:3210`；端口被占用时以实际显示地址为准。保持终端运行。
   可在「功能大厅 → 设置 → AI 模型」保存配置，再点「检测模型连接」。该栏目会列出你的 Key 实际可用的模型；选一项保存后，网页下一条消息即生效，终端界面重启后生效。
4. **导入课表**：在「功能大厅 → 设置」点「导入 / 重新导入课表」，粘贴课表文字，或上传 Excel / CSV / PDF / Word / TXT。解析后给你逐行可编辑的预览，拿不准的字段会先追问（最多 3 个问题），确认无误再入库——入库前会做时间冲突检测。
5. 点开「今日日程」或问一句「这周课表」，核对学期、教学周与一门课程的时间地点。

网页入口只监听本机。目前不提供手机直接远程访问，也不提供安装即用的手机 App；多人使用请各自安装、各自配置凭证。手机使用可以先从课表日历开始。

网页版还支持把 PDF、Word、Excel 等文件拖到输入框；文件保存在当前电脑的受控上传目录，AI 处理所需内容会发送到所选模型服务。查看课程时打开「功能大厅 → 课表」。

功能大厅在右侧栏内打开：「今日日程」显示当天课程，「课表」按星期列出本周课程，截止事项在「待办」里查看。课表面板只读本地缓存，不消耗模型调用；也可在对话里说「导出本周课表图片」，生成后保存到本机。

## 八个值得先试的问题

| 想做的事 | 直接这样问 | 使用结果时留意 |
|---|---|---|
| 看课表 | 这周课表，按每天整理地点和时间 | 开学日期若是估算，先核对学校校历 |
| 看今天 | 结合课表和待办，整理今天的安排 | 通过对话综合查询；具体记录在功能大厅侧栏核对 |
| 记待办 | 周五下午三点前交实验报告 | 相对日期会先跟你核对，没给截止时间会问一句 |
| 导出日历 | 把这周的待办导出成 .ics | 先下载再传到手机，导入方式取决于日历 App |
| 备考复习 | 用费曼法检查我对极限的理解 | 按请求加载对应学习技能，围绕你提供的内容展开 |
| 记住的事 | 上次说的报销截止是哪天来着？ | 长期事实自主沉淀，跨重启也在 |
| 记知识点 | 记一下傅里叶变换的直观含义 | 会按课表里的真实课程归类 |
| 用文件 | 把这份 PDF 的第三章总结成 Word | 长文分页续读、关键词定位，不整本塞给模型 |

你也可以明确指定学期，例如“这周的课表（2026-2027-1）”。表格筛选、文档生成与沙箱计算见[完整能力](capabilities.md)。

## 日历：导入和订阅怎么选

- **导入**：生成 `.ics`，下载后导入自己的日历。文件不需要公开；课表变更后需重新导出，注意避免重复导入。
- **订阅**：另行配置 GitHub/Gitee 令牌，发布后用链接订阅。目前实现使用公开仓库，课程、时间和地点可能被他人看到。工具会在首次发布前说明公开范围并请求确认。
- 订阅并不等于后台持续查课表；数据变化后需要重新运行发布，手机还会有刷新延迟。

## 常见问题

| 遇到的情况 | 可以怎么做 |
|---|---|
| 双击后闪退或提示版本过低 | 在终端运行 `node --version`，确认至少 v24；再执行 `npm run doctor` |
| 安装依赖失败 | 保留具体错误信息，检查网络后重跑 `npm ci`；不要把 `.env` 或整个项目目录发给别人 |
| 网页打不开 | 保持主程序运行；正式地址看启动提示，演示默认是 3211，正式默认是 3210 |
| 模型报认证、余额或模型不存在 | 核对自己的模型账户与所选模型；终端输入无参数 `/key` 可安全重设 Key |
| 课表解析不准 | 在导入预览里逐行改；课表文字尽量带上「课程名 / 周几 / 第几节 / 周次 / 地点」这几项 |
| 课表和学期对不上 | 开学日期按校历维护，未知学期按 9 月 / 3 月第一个周一估算并标注；放假 / 调休可以在对话里说一句让它落盘 |
| 中文 PDF 生成失败 | 需要系统中文字体；非 Windows 可通过 `RAPTOR_CJK_FONT` 指定已有字体文件 |

`npm run doctor` 只检查运行前提，不测试网络、API Key 余额或模型可用性。

## 分享给室友前

分享 GitHub 项目地址或维护者检查过的干净安装包，让对方配置自己的 Key。不要转发你已经使用过的整个目录：其中可能含凭证、完整聊天记录、课表、附件和生成的作业文件。

`npm run demo` 可录制界面预览，需保留“虚构数据”提示；它使用固定剧本，不能证明真实 AI 导入、保存或文件生成效果。正式功能演示应使用自备虚构材料。个人记录本地保存，但 AI 对话所需内容会发送到所选模型服务商，详见[隐私与安全](../SECURITY.md)。
