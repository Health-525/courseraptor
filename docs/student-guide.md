# 同学使用指南

[返回首页](../README.md) · [配置参考](configuration.md) · [完整能力](capabilities.md)

## 先体验，再配置

安装 Node.js 24 或更高版本后，下载项目并解压。在项目目录打开终端：

```bash
npm ci
npm run demo
```

打开终端提示的地址（默认 `http://127.0.0.1:3211`）。这是固定剧本的离线演示，全部使用虚构数据，没有连接教务或 AI。演示会话只保留在内存，服务重启即清空。不要在演示中填写学号、密码或个人资料。

结束演示按 `Ctrl+C`。正式使用运行 `npm start`，Windows 也可双击 `start.bat`。

## 第一次正式使用

1. 准备自己的南京工业大学教务账号，以及可用的 DeepSeek API Key。API 调用费用由你自己的模型服务账户承担。
2. 按终端提示输入学号、教务密码和 API Key。密码与 Key 输入时不回显，之后加密保存在本机。推荐使用引导，通常无需编辑 `.env`。
3. 打开启动界面显示的网页地址，默认 `http://localhost:3210`；端口被占用时以实际显示地址为准。保持终端运行。
4. 点击“这周课表”，核对学期、教学周与一门课程。再查询成绩，核对 GPA 口径和是否有查询失败的学期。

网页入口只监听本机。目前不提供手机直接远程访问、共享多账号网站或安装即用的手机 App。手机使用可以先从导入课表日历开始。

## 六个值得先试的问题

| 想做的事 | 直接这样问 | 使用结果时留意 |
|---|---|---|
| 看课表 | 这周课表，按每天整理地点和时间 | 开学日期若是估算，先核对学校校历 |
| 看学业概览 | 我的成绩和 GPA，有哪些未通过或待确认的课程？ | 已获学分与计入 GPA 的必修学分是两个数 |
| 核对通识修读 | 通识学分还缺哪些？把已通过课程按类别整理 | 类别覆盖不代表满足本专业最低学分 |
| 准备考试 | 最近的考试安排，按日期排序 | 未查到数据与没有考试是不同状态 |
| 读通知 | 教务处最近有什么通知？读和我相关的那条 | 重要日期、适用对象回到原文核对 |
| 同步日历 | 把本学期课表和考试导出成 .ics | 先下载再传到手机，导入方式取决于日历 App |

你也可以明确指定学期，例如“查询 2025-2026-2 的课表”。报告润色、表格筛选和文档生成见[完整能力](capabilities.md)。

## 日历：导入和订阅怎么选

- **导入**：生成 `.ics`，下载后导入自己的日历。文件不需要公开；后续课表变更需重新导出，注意避免重复导入。
- **订阅**：另行配置 GitHub/Gitee 令牌，发布后用链接订阅。目前实现使用公开仓库，课程、时间和地点可能被他人看到。工具会在首次发布前说明公开范围并请求确认。
- 订阅并不等于后台持续查课表；数据变化后需要重新运行发布，手机还会有刷新延迟。

## 常见问题

| 遇到的情况 | 可以怎么做 |
|---|---|
| 双击后闪退或提示版本过低 | 在终端运行 `node --version`，确认至少 v24；再执行 `npm run doctor` |
| 安装依赖失败 | 保留具体错误信息，检查网络后重跑 `npm ci`；不要把 `.env` 或整个项目目录发给别人 |
| 输入密码没有显示任何字符 | 这是正常的隐藏输入；输入完成按回车 |
| 网页打不开 | 保持主程序运行；正式地址看启动提示，演示默认是 3211，正式默认是 3210 |
| 登录失败 | 先确认自己的账号能登录学校教务网页，再检查网络；不要连续高频重试 |
| 模型报认证、余额或模型不存在 | 核对自己的模型账户与所选模型；终端输入无参数 `/key` 可安全重设 Key |
| 成绩为空或不全 | 查看错误和失败学期；失败不等于没有成绩。稍后重试并对照学校系统 |
| 更换教务账号后重启仍使用旧账号 | `.env` 的 `JWGL_*` 优先；若曾手动填写，请同步处理旧值，且勿在聊天中发送凭证 |
| 中文 PDF 生成失败 | 需要系统中文字体；非 Windows 可通过 `RAPTOR_CJK_FONT` 指定已有字体文件 |
| 选课按钮或工具不可用 | 默认关闭真实选课提交；学校模块也可能未开放，详见能力参考 |

`npm run doctor` 只检查运行前提，不测试学校登录、网络、API Key 余额或模型可用性。

## 分享给室友前

分享 GitHub 项目地址或维护者检查过的干净安装包，让对方配置自己的账号。不要转发你已经使用过的整个目录：其中可能含凭证、完整聊天记录、课表、附件和生成的作业文件。

建议用 `npm run demo` 录制演示；页面始终显示“虚构数据”。正式使用的数据去向见[隐私与安全](../SECURITY.md)。
