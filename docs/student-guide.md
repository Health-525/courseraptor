# 同学使用指南

[返回首页](../README.md) · [配置参考](configuration.md) · [完整能力](capabilities.md)

## 先体验，再配置

**推荐：下载安装包**（Windows 免装 Node，双击即用）——到 [Releases](https://github.com/Health-525/courseraptor/releases/latest) 下载 `portable-win-x64.exe`，双击即进入界面。开发者也可以源码运行：安装 Node.js 24 或更高版本后，下载项目并解压，在项目目录打开终端：

```bash
npm ci
npm run demo
```

打开终端提示的地址（默认 `http://127.0.0.1:3211`）。这是固定剧本的离线演示，全部使用虚构数据，不连接任何外部服务或 AI。演示会话只保留在内存，服务重启即清空。不要在演示中填写密码、API Key 或个人资料。

结束演示按 `Ctrl+C`。正式使用运行 `npm start`，Windows 也可双击 `start.bat`。

## 第一次正式使用

1. 准备任一家内置厂商的 API Key（默认 DeepSeek，共 12 家可选，见[配置参考](configuration.md)）。API 调用费用由你自己的模型服务账户承担。
2. 启动后打开界面显示的网页地址，默认 `http://localhost:3210`；端口被占用时以实际显示地址为准。保持终端运行。
3. 在「功能大厅 → 设置 → AI 模型」栏目保存 API Key，点击“检测模型连接”。「AI 模型」栏目会列出你的 Key 实际可用的模型，默认沿用 `deepseek-flash`（V4.1-Flash，图片输入原生支持）即可；想换别的型号（如 `deepseek-v4-pro`），选一项保存，网页下一条消息即生效。
4. 在「功能大厅 → 设置 → 导入课表」里粘贴你的课表文字（教务网页里的课表表格、Excel 导出、其他课表 App 的导出文本都行）或上传文件，AI 解析、追问与逐行确认后保存。开学日期在这一步填写，教学周按它推算。

程序不接入学校教务系统：不需要也不保存教务账号密码，查到的课表全部来自你导入的这份缓存。

网页入口只监听本机。目前不提供手机直接远程访问，也不提供安装即用的手机 App；多人使用请各自安装、各自配置。手机使用可以先从导出课表日历开始。

网页版还支持把 PDF、Word、Excel 等文件拖到输入框；文件只进入当前电脑的受控上传目录。课表查询结果会显示结构化卡片，手动刷新时与上次成功结果比较。

侧栏的「今日日程」会打开独立的本周课表页。它以周课表完整展示课程时间、地点、教师与周次，支持切换教学周；只读本地导入的缓存，不消耗模型调用。

## 八个值得先试的问题

| 想做的事 | 直接这样问 | 使用结果时留意 |
|---|---|---|
| 看课表 | 这周课表，按每天整理地点和时间 | 开学日期若是估算，先在导入预览里填准确日期 |
| 记待办 | 记一下周五交实验报告，23:59 截止 | 相对日期会先换算成绝对时间再保存 |
| 记知识点 | 把刚才讲的特征值解法记到高数里 | 知识按课表课程归类，跨会话可查 |
| 备考复习 | 帮我复习高数，下周三考试 | 教练模式按你给的考试时间排计划，不编造安排 |
| 记住的事 | 上次说的报销截止是哪天来着？ | 长期事实自主沉淀，跨重启也在 |
| 放假安排 | 下周国庆放假，10月10日周六补周三的课 | 说一句即落盘，课表与日历自动修正 |
| 同步日历 | 把本学期课表导出成 .ics | 先下载再传到手机，导入方式取决于日历 App |
| 课表壁纸 | 把课表导出成图片，红头档案风 | 整学期汇总或单周形态、PNG 或 SVG 都可选 |

你也可以明确指定学期，例如“查询 2025-2026-2 的课表”（本地缓存只有当前导入的学期）。报告润色、表格筛选和文档生成见[完整能力](capabilities.md)。

## 日历：导入和订阅怎么选

- **导入**：生成 `.ics`，下载后导入自己的日历。文件不需要公开；后续课表变更需重新导出，注意避免重复导入。
- **订阅**：另行配置 GitHub/Gitee 令牌，发布后用链接订阅。目前实现使用公开仓库，课程、时间和地点可能被他人看到。工具会在首次发布前说明公开范围并请求确认。
- 订阅并不等于后台持续同步；课表变更后需要重新运行发布，手机还会有刷新延迟。

## 常见问题

| 遇到的情况 | 可以怎么做 |
|---|---|
| 双击后闪退或提示版本过低 | 在终端运行 `node --version`，确认至少 v24；再执行 `npm run doctor` |
| 安装依赖失败 | 保留具体错误信息，检查网络后重跑 `npm ci`；不要把 `.env` 或整个项目目录发给别人 |
| 网页打不开 | 保持主程序运行；正式地址看启动提示，演示默认是 3211，正式默认是 3210 |
| 课表解析结果不对 | 在导入预览里逐行核对、就地编辑后再确认；换一种粘贴格式（如先转成纯文本）通常更稳 |
| 周次显示不对 | 教学周按导入时填的开学日期推算；在导入预览补填准确日期即可校准 |
| 模型报认证、余额或模型不存在 | 核对自己的模型账户与所选模型；终端输入无参数 `/key` 可安全重设 Key |
| 中文 PDF 生成失败 | 需要系统中文字体；非 Windows 可通过 `RAPTOR_CJK_FONT` 指定已有字体文件 |

`npm run doctor` 只检查运行前提，不测试网络、API Key 余额或模型可用性。

## 分享给室友前

分享 GitHub 项目地址或维护者检查过的干净安装包，让对方配置自己的 Key 与课表。不要转发你已经使用过的整个目录：其中可能含凭证、完整聊天记录、课表、附件和生成的作业文件。

建议用 `npm run demo` 录制演示；页面始终显示“虚构数据”。正式使用的数据去向见[隐私与安全](../SECURITY.md)。
