# CourseRaptor 手机端界面设计

## 设计目标

手机端以“掌上学习工作台”为方向：对话、今日安排与待办是高频任务，核心操作应落在拇指热区，首屏优先呈现内容和动作。保留暖纸底、墨色字、朱砂红与印章等品牌资产，不另起视觉体系。

桌面端布局、样式和交互保持不变。新增导航仅在 `max-width: 720px` 生效，打印时隐藏。

## 页面结构

- **对话**：压缩欢迎区，修正中文断行；提示词横滑，输入区固定在底部导航上方。只有文本框聚焦时才收起提示词，点击快捷提问或附件不会误收起。
- **今日**：页头收敛为一行，下一节课、倒计时与考试优先；重复页面导航交给底部标签栏。
- **课表**：手机默认“按天”视图，星期横滑选择，课程按时间顺序展开；“整周”保留原网格并自动定位今天。
- **待办**：标题、截止时间和删除分区排列；复选框扩大隐形触控热区。
- **知识**：搜索与分类保持可达，统计、发布和知识川流按阅读顺序排列。
- **共用导航**：对话、今日、课表、待办、知识五项，当前页同时以颜色、浅底和 `aria-current` 表达。

## 交互与状态

- 主按钮和底部标签在按压时给出短促反馈；抽屉与功能大厅继续沿用原交互。
- 今日内容首次进入轻微上浮，课表视图切换立即到位；减少动态效果模式下关闭动画。
- 保留原加载、空数据、错误、禁用和演示状态。离线演示中的周次翻页按钮禁用是预期行为。
- 输入控件维持 16px，主要操作目标不小于 44px；小复选框通过伪元素扩大热区。

## 验收重点

- 390×844 与 320×680 下无页面级横向溢出、遮挡或关键文字裁切。
- 快捷提问能真正发送；输入框聚焦时提示词收起，发送与停止正常。
- 按天/整周切换、星期选择、底部导航、菜单与功能大厅均可操作。
- 桌面端保留原三栏布局，不出现手机导航。
- 截图与交互证据位于 worktree 的 `outputs/mobile-ui-*` 目录。
