# 学生功能路线图

[返回首页](../README.md) · [提交建议](https://github.com/Health-525/courseraptor/issues/new?template=feature_request.yml)

服务对象：任何学校的学生——导入课表即可开聊，先解决日常查询与上手体验，再扩展持续使用场景。下面是基于当前代码与使用流程的产品判断，尚未经过学生访谈验证；优先级不是上线承诺。

## 本轮已完成

- 免 API Key 的离线演示，使用正式网页视图与虚构数据。
- 启动自检和 Windows Node.js 24 版本检查。
- 网页常用问题增加日历导出，并说明模型服务的数据去向。
- 安装包排除本机数据，升级保护聊天、附件、生成文件和个人校历记录。
- 学生 README、分层文档、贡献指南、问题表单与 CI 配置。
- 网页会话搜索、改名、置顶与窄屏会话抽屉。
- 浏览器文件上传、课表结果卡。
- 设置连接检测、截止日期待办、`.ics` 导出与本地数据导出/清理。
- 本周课表独立页（`/today`）：按周课表完整展示课程，支持切换教学周；纯本地缓存渲染（新增考试缓存），不调模型。
- 2026-10 新增：学习教练（期末备考「模板→变式→整卷」编排）；知识库独立页 `/knowledge` flomo 式改版（发布框 + 标签侧栏 + 16 周热力带）；功能大厅「用量统计」面板（一年 53 周热力图 + 四格摘要 + 各模型分布）；「提示词模板」面板；PPT 课件生成与翻页预览；课表图片导出；QQ 官方机器人四端接入。
- 2026-10 收敛：课表改为**手动导入**（网页设置页粘贴文字或上传文件，解析后逐行确认入库）；课表类工具改为**只读本地缓存**（`get_schedule` 不联网，`set_holidays` 落盘放假调休）；全局 HTTP 重试收紧到 2 次（首次 + 一次重试，早失败胜过转圈）；移除验证码 OCR 能力（附件遇图形验证码直接失败并提示手动下载，不做绕过）。
- 2026-10 新增：**Obsidian 插件（第四端入口）**——侧栏流式对话（同一内核与记忆）、今日日程与待办一键插入笔记；服务端配套「本地 API 令牌」（`data/local-api.json` 长期令牌，写请求与 CSRF 二选一过门）与 `app://obsidian.md` 的 CORS 放行，网页「设置 → Obsidian 插件」展示连接信息。

## 暂不优先

- 空闲教室、图书馆占座等依赖尚未核实可用来源的功能，先调查数据来源。
- 无来源的毕业资格判断、奖学金排名预测和自动替学生提交申请。
- 多用户托管服务（网关/管理台/更新后台）已于 2026-10 整体下线，项目专注纯本地；QQ 白名单仍不是多账号隔离。
- 将真实写操作类能力作为推广主卖点；长期价值应来自日程、待办与学习。

## 如何决定下一个版本

先邀请少量自愿参与的同学，分别完成安装、导入课表、记待办、日历导出四项任务。只记录是否完成、卡在哪一步和是否愿意继续使用，不收集个人数据或完整聊天。

优先修复多人重复遇到的阻碍，再从上表选择一个需求做完整闭环。功能建议应描述“什么时候需要、现在怎么解决、怎样算好用”，而不只是工具名称。
