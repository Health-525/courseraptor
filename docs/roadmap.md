# 学生功能路线图

[返回首页](../README.md) · [提交建议](https://github.com/Health-525/courseraptor/issues/new?template=feature_request.yml)

> **2026-10-07 重大变更**：出于合规考虑，仓库移除了全部学校的在线教务适配器（不保存教务密码、不代登录、不请求教务系统），产品统一为「用户自行导入数据」的本地学习助理；下文涉及在线教务查询（成绩 / 考试 / 选课 / 通知）的已完成条目均为历史记录，对应功能已随适配器一并移除，历史实现见仓库 git 历史与维护者本地留档。

服务对象：使用手动导入数据模式的在校学生，先解决日常组织与上手体验，再扩展持续使用场景。下面是基于当前代码与使用流程的产品判断，尚未经过学生访谈验证；优先级不是上线承诺。

## 本轮已完成

- 免配置、免 API Key 的离线演示，使用正式网页视图与虚构数据。
- 启动自检和 Windows Node.js 24 版本检查。
- 网页常用问题增加日历导出，并说明模型服务的数据去向。
- 安装包排除本机数据，升级保护聊天、附件、生成文件和个人校历记录。
- 学生 README、分层文档、贡献指南、问题表单与 CI 配置。
- 网页会话搜索、改名、置顶与窄屏会话抽屉。
- 浏览器文件上传、课表结果卡和手动刷新变化对比。
- 设置连接检测、通知截止日期待办、`.ics` 导出与本地数据导出/清理。
- 本周课表独立页（`/today`）：按周课表完整展示课程，支持切换教学周；纯本地缓存渲染，不调模型。
- 2026-10 新增：学习教练（期末备考「模板→变式→整卷」编排）；知识库独立页 `/knowledge` flomo 式改版（发布框 + 标签侧栏 + 16 周热力带）；功能大厅「用量统计」面板（一年 53 周热力图 + 四格摘要 + 各模型分布）；「提示词模板」面板；PPT 课件生成与翻页预览；课表图片导出；QQ 官方机器人三端接入。
- 2026-10-07 转向：移除全部学校教务适配器，统一手动导入课表模式；日历导出与课表图工具迁移到手动模式工具集。

## 下一步优先做什么

| 优先级 | 功能 | 学生得到什么 | 首版范围 | 验收标准与依赖 |
|---|---|---|---|---|
| P1 | ~~本周课表~~ **已完成**：独立页 `/today`，断网显示缓存时间 | 打开即可完整查看任意教学周的课程 | 从缓存以周课表展示课程，支持切换教学周 | 断网显示旧数据时间；单双周、调休正确；不每次打开都调用模型 |
| P1 | 截止日期待办与提醒 | 少错过报名、补选、材料提交 | **网页首版已完成**：用户转述日期 → 确认 → 本地待办和 .ics；后续再评估程序关闭后的系统通知 | 每条有原文来源；支持完成；日期不明确时不自动创建 |
| P1 | 课表变更对比 | 换学期 / 换教室后知道课表变了 | **网页首版已完成**：手动刷新时与上次成功快照比较 | 请求失败不覆盖快照；只提示实际变化 |
| P2 | 学习计划产品化 | 把考试日期变成可执行复习安排 | **部分完成**：学习教练已可排考试型复习路径（模板→变式→交叉→整卷，考试时间由用户提供）；产品化的可编辑计划待做 | 不把所有空课时都视为可用；支持休息与延期；修改后能同步更新 |
| P2 | 安装与配置进一步简化 | 不熟悉终端的学生也能顺利完成首问 | **网页已完成连接检测**；后续补首次配置分步向导和恢复入口 | 新设备按文档完成安装；未配置也能浏览帮助；凭证不进入聊天历史 |
| P3 | ~~成本与数据管理~~ **已完成**：功能大厅「用量统计」面板 + 本地数据导出/清理 | 清楚哪些内容发给模型、如何清理历史 | 用量统计面板（一年 53 周热力图、四格摘要、各模型分布）与 `/api/data/export`、`/api/data/clear` 已上线 | 以实际返回用量为准；清理前预览范围并确认；不默认上传行为分析 |
| P3 | ~~多校适配~~ **已完成并于 2026-10-07 移除**：HEBAU 适配器（社区贡献，PR #204）曾随 `SchoolAdapter` 端口合入，后因合规考虑与全部在线教务适配器一并移除 | 学校无关：任何学校学生手动导入课表即用 | `SchoolAdapter` 端口保留（接合规数据源仍可即插即用）；内置实现仅手动课表模式 | 历史实现在仓库 git 历史与维护者本地留档 |

## 暂不优先

- 空闲教室、图书馆占座等依赖尚未核实可用接口的功能，先调查数据来源。
- 无来源的毕业资格判断、奖学金排名预测和自动替学生提交申请。
- 多用户托管服务（网关/管理台/更新后台）已于 2026-10 整体下线，项目专注纯本地；QQ 白名单仍不是多账号隔离。
- 重新接入学校教务系统：除非出现官方授权的数据源，不再走模拟登录路线。

## 如何决定下一个版本

先邀请少量自愿参与的同学，分别完成安装、导入课表、日历导出四项任务。只记录是否完成、卡在哪一步和是否愿意继续使用，不收集学号或完整聊天。

优先修复多人重复遇到的阻碍，再从上表选择一个需求做完整闭环。功能建议应描述“什么时候需要、现在怎么解决、怎样算好用”，而不只是工具名称。
