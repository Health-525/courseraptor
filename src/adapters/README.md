# 校内数据接入层

本目录是 CourseRaptor 的**校内数据接入点**。内核（`src/core`）只依赖
`src/core/school.ts` 定义的学校端口，不关心课表数据从哪来；学期规则、
节次作息与课表来源都在这里实现。

## 目录约定

```
src/adapters/
├── index.ts      # 装配点：登记内置实现，按设置页保存的 schoolId 选定默认学校
├── custom/       # 内置实现：手动导入课表（「其他学校」）
└── README.md     # 本文件
```

`custom` 是唯一内置实现＝「其他学校（手动课表）」：不指向任何真实学校、
零教务联网，课表来自用户在设置页导入的本地缓存。设置页的学校下拉由
`core/school` 的登记表驱动；接入新数据源＝实现一个符合端口
（`src/core/school.ts`）的对象并在装配点登记。

默认学校取凭证里保存的 `schoolId`；没有或已不可用时回落 `custom`。
